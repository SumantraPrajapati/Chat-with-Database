# Talk With Database

An **AI-powered database assistant** built with **Google ADK** and **Gemini 2.5 Flash** that allows users to interact with a SQLite database using natural language.

Instead of manually writing SQL queries, users can ask questions such as:

> "How many customers are there?"

> "Rahul ne kitne orders kiye?"

> "Which artist has the most albums?"

The AI agent understands the question, generates an appropriate **read-only SQL query**, executes it against the database, and explains the result in simple language.

---

##  Features

*  **Google ADK-based AI Agent**
*  Powered by **Gemini 2.5 Flash**
*  SQLite database integration
*  Automatic database schema inspection
*  Natural-language-to-SQL generation
*  Read-only database access
*  Protection against destructive SQL operations
*  Supports **English, Hindi, and Hinglish**
*  Supports SQL joins and aggregations
*  Natural-language explanation of query results
*  Prevents `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, and other destructive operations

### `agent.py`

Defines the main Google ADK agent.

The agent:

* Uses Gemini 2.5 Flash
* Receives the database schema
* Understands the user's question
* Generates SQL when database information is required
* Calls the database tool
* Explains the result

The main agent is exposed as:

```python
root_agent = LlmAgent(...)
```

---

### `database.py`

Responsible for inspecting the SQLite database schema.

It extracts:

* Table names
* Column names
* Data types

The schema is then provided to the AI agent so that it knows what information is available in the database.

Example schema representation:

```text
[
    ['customers', 'CustomerId', 'FirstName', 'LastName', ...],
    ['invoices', 'InvoiceId', 'CustomerId', 'InvoiceDate', ...],
    ['tracks', 'TrackId', 'Name', 'AlbumId', ...]
]
```

---

### `tools.py`

Contains the database tool used by the ADK agent.

The tool accepts SQL generated by the agent:

```python
database_tool = FunctionTool(
    func=query_database
)
```

Only read operations are intended to be permitted.

Destructive operations such as:

```text
INSERT
UPDATE
DELETE
DROP
ALTER
TRUNCATE
REPLACE
ATTACH
DETACH
```

are blocked.

#  How It Works

Suppose the user asks:

```text
How many customers are there?
```

### Step 1 — Understand the question

Gemini determines that the answer requires database information.

### Step 2 — Inspect the available schema

The agent already receives the database schema during initialization.

For example:

```text
customers
├── CustomerId
├── FirstName
├── LastName
└── Email
```

### Step 3 — Generate SQL

The agent can generate:

```sql
SELECT COUNT(*) AS customer_count
FROM customers;
```

### Step 4 — Execute the query

The query is passed to:

```python
database_tool
```

### Step 5 — Return the result

SQLite returns the result.

### Step 6 — Explain it

The agent converts the database result into a natural-language response.

```text
There are 59 customers in the database.
```

#  Read-Only Database Access

Database safety is an important part of this project.

The database tool validates incoming SQL before execution.

For example:

```python
if not sql_clean.startswith("select"):
    return {
        "success": False,
        "error": "Only SELECT queries are allowed"
    }
```

It also checks for blocked operations such as:

```text
INSERT
UPDATE
DELETE
DROP
ALTER
TRUNCATE
REPLACE
ATTACH
DETACH
```

This prevents the AI agent from intentionally or accidentally modifying the database.

> **Important:** SQL string filtering is useful as a basic safeguard, but for production systems it should be combined with stronger database-level read-only permissions and query validation.

#  Running the Agent

Google ADK projects can be launched using the ADK development interface.

From the directory containing your agent package:

```bash
adk web
```

For example:

```text
talk with database/
│
├── chinook.db
└── database_assistant/
    ├── __init__.py
    ├── agent.py
    ├── database.py
    └── tools.py
```

Run:

```bash
cd "talk with database"
adk web
```

ADK will discover the `database_assistant` agent.

---
if adk web doesn't work try 
```bash
python -m google.adk.cli web
```

#  Why This Project?

Traditional database interaction requires users to know SQL:

```sql
SELECT COUNT(*)
FROM customers;
```

This project provides a natural-language interface:

```text
"How many customers are there?"
```

The AI handles the translation:

```text
Natural Language
       ↓
      LLM
       ↓
     SQL
       ↓
   Database
       ↓
    Result
       ↓
Natural Language
```

The goal is to make structured data accessible to users who don't necessarily know SQL.
